## Speaker 1

### GitHub Copilot Surfaces: My Leveling Up with AI

🎤 [Rob Bos](https://www.linkedin.com/in/bosrob/)

GitHub Copilot is everywhere now.
Inline.
In chat.
Agent mode.
The CLI.
The app.
The cloud.

But which one should you actually use, and when?

Rob is going to take us through his own journey of leveling up with GitHub Copilot and exploring the different Copilot surfaces over time.
From starting with single-session, single-branch work to running multiple agents concurrently and merging their results.
This is not just a "look what Copilot can do" session.
It is about how the way you work changes as you move up the Copilot ladder.

If you're already using GitHub Copilot, you'll hopefully pick up some new tricks.
If you're just getting started, you'll get a great look at what's possible.

## Speaker 2

### Stop Prompting and Praying, Start Specifying: Build a Full Application in 60 Minutes

🎤 [Paul Stolk](https://www.linkedin.com/in/paul-stolk-62ab442b/)

We all know the feeling...
You have an idea.
You open Copilot.
You start prompting.
And then... you start praying. 😂

But what if you could start with a proper specification instead?

In this session, we'll dive into Spec-Driven Development (SDD) and see how it can completely change the way you work with Copilot.
We'll go beyond the single prompt and create a structured plan for what we actually want to build.

We'll get hands-on with Spec Kit and Open Spec, explore the differences between them, and then put them to the test by building a working application from scratch.

All in 60 minutes!
