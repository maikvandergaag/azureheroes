Join us for an exciting day of learning and networking at the Global Azure 2025 event hosted by Azure Heroes Netherlands. This full-day extravaganza promises engaging sessions led by top-notch speakers from the Azure community — whether you're an Azure veteran or just beginning your cloud journey. This is a ticket-only event; tickets are free, so please only reserve one if you can attend (zero waste).

## Featured speakers

### Mathijs Vermaat

**Risk Mitigation with Defender for Cloud**

A practical session exploring vulnerability management, threat detection, and risk mitigation strategies across hybrid and cloud workloads using Microsoft Defender for Cloud.

### Bogdan Grozoiu

**Azure Vol**

Deep dive with Bogdan Grozoiu from Schuberg Philis on Azure engineering and operational resilience.

### Maik van der Gaag

**Deploying Resources to Azure with Bicep and GitHub: Infrastructure as Code and Testing**

Learn how to build, test, and automate scalable cloud infrastructure deployments with Bicep and GitHub Actions.

### Melissa Paasen

**404: Cost Not Found – FinOps for Engineers**

Explore FinOps principles, cost monitoring, and architectural choices that keep cloud costs in check without compromising scalability.

### Jev Suchoi

**The Perfect Azure Naming Convention: Designing for Scalability and Automation**

Design enterprise-grade naming conventions and tagging strategies that streamline automation, governance, and cloud platform maintenance.
